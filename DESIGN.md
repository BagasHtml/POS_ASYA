# Asya POS - Design Direction

## Brand Identity
- Nama: Asya POS (Astro + Elysia)
- Tujuan: POS sederhana, bersih, profesional untuk operasional sehari-hari
- Tone: Profesional, praktis, tidak berlebihan

## Visual Direction
- Style: Clean, minimal, utilitarian (fokus fungsi, bukan dekoratif)
- Approach: Purposeful, tidak AI-generic, hindari glow/shimmer/decorative arrows

## Dials (R-37)
- ENERGY: 1 (tenang, stabil)
- RHYTHM: 1 (konsisten, terprediksi)
- MOTION: 1 (minimal, hanya bila perlu untuk feedback)

## Color & Typography
- Palette: Neutral (grays) + accent single primary untuk action
- Contrast: WCAG AA minimum (R-25)
- Typography: System font stack, readable, hierarki jelas

## UX Principles
- Mobile-first, responsive, mobile perfect (R-03)
- Keyboard accessible (R-32), focus visible
- States lengkap: empty/loading/error/success (R-27)
- Interaktif jelas (R-26), hindari fake UI
- Setiap keputusan punya alasan (R-31)
- Verifikasi click-through terrecord (R-35)
